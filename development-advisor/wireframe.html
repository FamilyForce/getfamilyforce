📐 Design Notes — v2 Changes & Rationale

Screens 1A–1B — Upsell
Pricing & Trial Changes
  • Removed 7-day free trial — cleaner conversion funnel
  • Monthly vs Annual toggle on upsell screen
  • Annual plan defaults to selected (savings highlighted in green badge)
  • $9.99/mo or $79.99/yr (~$6.67/mo effective) — $39 savings
  • CTA button dynamically shows selected plan price
  • No annual vs. monthly complexity elsewhere in the app
Screen 1C — Gift Code
Gift Flow (Baby Shower Use Case)
  • New screen: "Have a gift code? Redeem it here" link on upsell
  • Gift purchaser buys from a separate gift page (to be designed)
  • Recipient enters the code (e.g., FF-BABY-2026) — validates instantly
  • Shows gifter's name if available: "Gifted by: Grandma Linda 💜"
  • No payment info required to activate
  • Unlocks the same 1-year annual plan as a paid subscriber
  • Opportunity: gift page = referral vector and gifting occasion
All Screens — Logo
FamilyForce Logo
  • Replaced text-only "FamilyForce" with hex icon + wordmark
  • SVG inline — no external asset dependency (consistent with zero-dep policy)
  • Icon: purple rounded rectangle + white chevron/crossbar (matches favicon.svg)
  • Used consistently in all nav bars, share cards, and branded surfaces
Screens 3A — Main Digest
Family Circle Access
  • Family Circle indicator below child switcher — shows linked members
  • Onboarding completion screen mentions family access
  • Shared read access: all circle members see the same digest
  • Shared write: to-do checkboxes sync across family members (future consideration)
  • Access managed via existing Family Circle code system (FF-XXXX)
  • No extra charge for family members — emphasised in upsell
Settings — 4C
3-Child Limit
  • Limit changed from 5 → 3 children
  • "Need more? Contact us" link — no hard wall, manual exception path
  • Slot counter shown: "2 of 3 children"
  • Rationale: 3 children covers the large majority of families; edge cases handled manually
Screen 4A — Share Card
Share UX & Referral QR
  • Removed all social platform icons (WhatsApp, Instagram, Facebook)
  • Single action: "Copy Image to Clipboard" — user pastes wherever they want
  • QR code explicitly labelled as referral link (not just decoration)
  • Referral mechanic: if a scanned user subscribes, purchaser earns renewal credit
  • Card includes FF logo + website — brand-consistent even off-platform
  • Copy Image uses html2canvas (already approved as the one exception)
Screen 3B — Cards
CPR Skip / Already Done Option
  • CPR milestone has "Already done · Skip ✓" button in card footer
  • Skip is permanent (unlike Dismiss) — shown in grey in Dismissed section
  • Skip applies to any milestone that may not be relevant (CPR, car seat check if already done, etc.)
  • UX note: "Skip" is different from "Dismiss" — Dismiss is hidden until restored; Skip implies completion
  • Both appear recoverable at the bottom of the Wins section
Open Questions
Things to Confirm Before Build
  • Does to-do checkbox state sync across Family Circle? (e.g. dad checks it, mom sees it checked)
  • Does the gift code live in Supabase? What table? (suggest: gift_codes table)
  • Referral QR — is there a referral program, or is this just brand awareness?
  • Monthly plan: does it exist in Stripe? Or annual only?
  • Family Circle access: read-only for members, or full control for members too?
