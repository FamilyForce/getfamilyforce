What's Needed to Build
Full Gift Flow — Build Checklist
Everything required to ship this from mockup to production.
🗄️ Database
  • scout_gifts table (code, tier, status, giver info, recipient info, redeemed_at)
  • generate_gift_code() function (unique, collision-safe)
  • RLS: giver can see own gifts; recipient can redeem by code
💳 Stripe
  • 3 gift Price IDs: $9.99/mo · $69.99/yr · $99.99/3yr
  • Gift checkout session (no account required)
  • Webhook: payment_intent.succeeded → create gift record + send emails
⚡ Edge Functions
  • create-gift: Stripe checkout → gift record → send giver email
  • redeem-gift: validate code → create child profile → activate Scout
  • generate-card-image: html2canvas/Satori → PNG → attach to email
📧 Emails (4 total)
  • Giver confirmation + digital card + printable PDF + shareable image
  • Recipient gift notification (from giver, personalised message)
  • Recipient activation confirmation
  • Giver notification: "They activated your gift!"
📄 Pages
  • gift-checkout.html — purchase flow (name, message, schedule)
  • gift-confirm.html — post-purchase: download card, share image
  • redeem.html — recipient enters code + sets up child profile
🖨️ PDF Generation
  • Puppeteer (server-side) or Browserless.io for printable card PDF
  • Triggered on purchase, stored in Supabase Storage
  • Download link in giver confirmation email (expires 30 days)
