What's Needed to Build
Full Gift Flow — Build Checklist
Everything required to ship this from mockup to production.
🗄️ Database
  • scout_gifts table (code, tier, status, giver, recipient, redeemed_at)
  • generate_gift_code() — unique, collision-safe
  • RLS: giver sees own; recipient redeems by code
💳 Stripe
  • 3 Price IDs: $9.99 · $49.99 · $99.99
  • Gift checkout (no account required)
  • Webhook: payment_intent.succeeded → gift record + emails
⚡ Edge Functions
  • create-gift: checkout → gift record → send giver email
  • redeem-gift: validate code → create profile → activate
  • generate-card-image: Satori/html2canvas → PNG
📧 Emails (4)
  • Giver: confirmation + digital card + printable PDF + share image
  • Recipient: gift notification with personal message
  • Recipient: activation confirmation
  • Giver: "They activated your gift!"
📄 Pages (3)
  • gift-checkout.html — name, message, schedule delivery
  • gift-confirm.html — download card, share image
  • redeem.html — code entry + child profile setup
🖨️ PDF Generation
  • Puppeteer or Browserless.io for printable PDF
  • 3 templates (one per tier)
  • Stored in Supabase Storage, download link expires 30 days
