Key Design Decisions (v2)
✂️
No Path C
Everyone starts with a 7-day trial. Want the full year? Just don't cancel.
📖
Library, not picker
Free users land in My Account / Library. Fewer steps, more freedom to explore.
🐔
Escape hatch
Two chances to bail out: child setup and payment. Both land in the library with a soft Scout upsell.
🎟️
Referral code
On payment screen. Applies discount live. Summary box updates to show new price before charging.
